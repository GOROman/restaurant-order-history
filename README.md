# 食事の記録

スマホ向けの食事写真・注文履歴・割り勘ページ。実際の注文内容と価格は未取得のため初期表示は空です。

品名、数量、単価を手入力して記録します。データはこのブラウザーのlocalStorageにのみ保存し、外部送信しません。個々の記録を削除できます。共用端末では削除してください。ブラウザーの保存データを消すと記録も消えます。

合計は数量×単価。税・サービス料等は自動補正しません。割り勘は初期5名。整数円で割り、余りの人数だけ1円多く負担する表示です。人数は1〜100、数量は1〜999、単価は0〜1,000,000円、記録は100件まで。

取り込み、注文、カート、決済、Airレジの自動同期機能はありません。公開承認済みの写真3枚のみを掲載し、不要なメタデータを除去しています。未確認の商品名や価格を写真から推定していません。

`npm test` で検証。`python3 -m http.server 8000` で起動。GitHub Pagesでmainのルートを公開します。
