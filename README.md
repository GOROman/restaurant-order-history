# 注文の記録

スマホ向けの日本語注文履歴アプリ。依存ライブラリやビルド不要の静的サイトです。

**実際の注文履歴は未取得です。** Airレジ オーダーの公式アプリではなく、自動取得・自動同期はできません。注文、取消、支払い機能はありません。

## 使い方

テキスト（1行ごとに `商品名,数量,単価,日時`）またはJSON配列（`name`, `quantity`, `unitPrice`, `orderedAt`）を入力し、プレビューで確認後に保存します。日時は省略可。金額は整数の円。表示合計は数量×単価で、税・サービス料等は自動補正しません。

デモは架空データと明示され、保存されません。履歴はブラウザーのlocalStorageにのみ保存します。同じ端末でも別ブラウザーには共有されません。サイトからデータの外部送信は行いません。QRセッショントークン、実履歴、卓番号、個人情報はソースや公開ファイルへ追加しないでください。

公開承認済みの食事写真3枚をアルバムに掲載しています。写真のEXIF等のメタデータは除去済み。写真から注文の商品名、数量、価格、日時は推定していません。

## 開発と公開

`python3 -m http.server 8000` で起動。`npm test` で取り込みと金額計算をテスト。GitHub Pagesはmainブランチのルートを公開します。公開サイトのアクセスに伴う標準ログはホスティング事業者の管理です。
